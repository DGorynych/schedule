# Schedule Management System - Server

## Description
Server application for collaborative employee schedule management in local network.

## Installation
1. Install Python 3.7+
2. Install dependencies: `pip install pyqt5`
3. Run: `python schedule_server.py`

## Compilation
Run `compile_server.bat` to create executable file.

## Usage
1. Start the server
2. Configure auto-start if needed
3. Server will run in system tray
4. Clients connect via specified IP and port

## Settings
- Default port: 8888
- Database: schedule_server.db
- Logs displayed in interface
