# Система управления расписанием - Серверная часть

## Описание
Серверное приложение для совместной работы с расписаниями сотрудников в локальной сети.

## Установка
1. Установите Python 3.7+
2. Установите зависимости: `pip install pyqt5`
3. Запустите: `python schedule_server.py`

## Компиляция
Запустите `compile_server.bat` для создания исполняемого файла.

## Использование
1. Запустите сервер
2. Настройте автозапуск при необходимости
3. Сервер будет работать в системном трее
4. Клиенты подключаются по указанному IP и порту

## Настройки
- Порт по умолчанию: 8888
- База данных: schedule_server.db
- Логи выводятся в интерфейсе
