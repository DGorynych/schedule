# Schedule Management System - Server

## Description
Server application for collaborative employee schedule management in local network.

## Installation
1. Install Python 3.7+
2. Install dependencies: `pip install pyqt5`
3. Run: `python schedule_server.py`

## Compilation
Run `compile_server.bat` to create executable file.

## Usage
1. Start the server
2. Configure auto-start if needed
3. Server will run in system tray
4. Clients connect via specified IP and port

## Settings
- Default port: 8888
- Database: schedule_server.db
- Logs displayed in interface






# Система управления расписанием - Серверная часть

## Описание
Серверное приложение для совместной работы с расписаниями сотрудников в локальной сети.

## Установка
1. Установите Python 3.7+
2. Установите зависимости: `pip install pyqt5`
3. Запустите: `python schedule_server.py`

## Компиляция
Запустите `compile_server.bat` для создания исполняемого файла.

## Использование
1. Запустите сервер
2. Настройте автозапуск при необходимости
3. Сервер будет работать в системном трее
4. Клиенты подключаются по указанному IP и порту

## Настройки
- Порт по умолчанию: 8888
- База данных: schedule_server.db
- Логи выводятся в интерфейсе
